Problem

AI agents can now hold keys and trade. The LLM deciding the trade can be prompt-injected, hallucinate, or chase losses. Today the only safety is a system prompt and offchain checks, which the same compromise can bypass.

Funds, family offices and regulated users on HashKey will not delegate capital to an agent whose limits live in a prompt. They need limits a contract enforces, tied to who the user is (KYC), and an audit trail they can show a regulator.

Solution

Vyuh the layer

Owner signs an EIP-712 Risk Mandate. Every agent trade is a structured intent checked onchain by seven policy rings before it can touch HSKSwap. Agent can tighten limits, never loosen them. KYC SBT tier sets the ceiling. Daily loss limit from oracle NAV auto-halts the vault.

Plugs into any agent via MCP server, SDK or direct contract call.

Chakravyuh the proof

A live agent with a real USDT pot behind Vyuh. Anyone can chat and try to jailbreak it. Fool the LLM and get a small bounty when the contract still blocks you. Beat the contract and take the pot.

Every attempt becomes data for an open agent-attack corpus and a security score.

Functional requirements

Contracts

  1. FR-1Owner signs EIP-712 mandate: per-trade cap, max position, token allowlist, max slippage, oracle band, daily loss %, expiry, min KYC tier.
  2. FR-2Vault executes only intents that pass every policy module; failure reverts with a reason code.
  3. FR-3Agent may call tighten(); any loosening requires a fresh owner signature.
  4. FR-4Anyone may call halt() when KYC is revoked, daily loss is hit, or the oracle is stale.
  5. FR-5Each trade emits a receipt: intentHash, reasoningHash, policy bitmap, NAV before and after.
  6. FR-6Owner can withdraw all funds at any time, including while halted.

Backend

  1. FR-7Runtime turns market signal into a structured intent, preflights with checkIntent(), submits only on pass.
  2. FR-8Keeper watches oracle staleness, SBT status and loss limit; calls halt within one block of trigger.
  3. FR-9Indexer serves receipts, NAV series, rejections and leaderboard over a REST API.
  4. FR-10MCP server exposes get_mandate, quote, propose_trade, get_positions, get_pnl, explain_rejection.

Arena

  1. FR-11Public chat with the honeypot agent; each attempt logs prompt hash, resulting intent and revert reason.
  2. FR-12Tier 1 bounty when the LLM emits a malicious intent and the contract blocks it; Tier 2 pot if funds move past the contract.
  3. FR-13Payout requires a KYC SBT (or allowlist fallback). Attempts are free.
